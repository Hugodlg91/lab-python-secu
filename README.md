Lab et TPs Python Scripting Sécurité — M1 Cyber
# 🛡️ Cursus Python Sécurité - ITIS

Bienvenue dans le laboratoire pratique du cours **Python Sécurité**. Ce dépôt contient 11 Travaux Pratiques (TPs) répartis sur 3 jours de formation, entièrement pré-configurés pour s'exécuter dans **GitHub Codespaces**.

## 🚀 Prise en main rapide

1. Cliquez sur le bouton vert **Code** en haut à droite du dépôt GitHub.
2. Sélectionnez l'onglet **Codespaces**, puis **Create codespace on main**.
3. Une fois l'environnement chargé, ouvrez le terminal et lancez le TP de votre choix.

---

## 📅 Programme des 3 Jours

### **Jour 1 : Reconnaissance, Scanning & Réseau**
* `python3 tp1_scanner.py` : Port Scanner TCP et détection de bannières.
* `python3 tp2_ping_sweep.py` : Découverte d'hôtes actifs par sockets multithreadés.
* `python3 tp3_arp_sniffer.py` : Détection des attaques ARP Poisoning via Scapy.
* `python3 tp4_ssh_bruteforce.py` : Simulation d'attaque par dictionnaire SSH avec Paramiko.

### **Jour 2 : Parsing de Logs, Crypto & Reverse Engineering**
* `python3 tp5_log_parser.py` : Analyseur d'attaques HTTP dans un fichier `access.log`.
* `python3 tp6_crypto_aes.py` : Chiffrement et déchiffrement symétrique AES-256.
* `python3 tp7_hash_cracker.py` : Cassage par dictionnaire d'empreintes MD5 / SHA-256.
* `python3 tp8_pe_analyzer.py` : Analyse statique Forensics d'un binaire exécutable PE.

### **Jour 3 : Threat Intelligence, Automation Web & Projet CTF**
* `python3 tp9_threat_intel.py` : Interrogation d'APIs de Threat Intelligence (Réputation IP).
* `python3 tp10_web_audit.py` : Audit des en-têtes de sécurité HTTP et scraping de formulaires.
* `python3 tp11_ctf_final.py` : Challenge CTF final combinant automation offensive et défensive.
